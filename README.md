# Anja Lash Studio

Mobilni web sajt za **Anja Lash Studio** (Anja Verem) — Mrkonjić Grad.

**Slogan:** Beauty in every blink  
**Instagram:** [@anja.lashstudio](https://instagram.com/anja.lashstudio)

## Pokretanje

Otvori `index.html` u pregledniku ili pokreni lokalni server:

```bash
python3 -m http.server 8080
```

Zatim posjeti `http://localhost:8080`.

## Struktura

- `index.html` — sadržaj stranice
- `styles.css` — stilovi (brand paleta iz logo branding sheet-a)
- `script.js` — navigacija i scroll animacije
- `assets/` — logo, hero, galerija, certifikat
- `anja.mp4`, `anja3.mp4` — video radova
